# DataCollectSystem 分布式数据采集系统

**DataCollectSystem** 是一套基于 Java + Vue 技术栈构建的分布式数据采集与管理平台，采用「采集节点-中心服务-前端界面」三层解耦架构，支持多节点并行采集、统一任务调度、可视化运维管理，可快速落地各类结构化数据的批量采集与标准化管理场景。

## ✨ 项目简介
系统采用分布式设计思想，将采集执行层、核心服务层、前端展示层完全拆分：爬虫节点可独立部署、横向扩展，中心服务端统一负责任务调度与数据治理，前端提供可视化操作界面。整体架构轻量灵活，既支持单节点快速启动测试，也支持多节点分布式部署，满足不同规模的数据采集需求。

## 🔥 核心功能
- **分布式采集节点**：`crawlernode` 支持多实例独立部署，并行执行采集任务，支持节点动态扩缩容
- **统一任务调度**：服务端集中管理采集任务，支持任务配置、下发、状态监控与执行日志追踪
- **数据治理能力**：内置数据清洗、去重、格式标准化逻辑，采集数据统一持久化存储
- **可视化管理界面**：基于 Vue + TypeScript 构建的 Web 管理端，提供任务配置、节点监控、数据查询能力
- **模块化扩展设计**：各层职责分离、接口清晰，可快速拓展新采集源、数据处理规则与业务功能

## 🛠️ 技术栈
| 模块 | 技术栈 |
|------|--------|
| 爬虫采集节点 | Java |
| 中心服务端 | Java |
| 前端管理界面 | Vue + TypeScript |

## 📁 项目结构
```
DataCollectSystem/
├── crawlernode/   # 爬虫采集节点：执行具体数据采集任务，支持分布式多节点部署
├── server/        # 中心服务端：任务调度、数据管理、API 接口服务核心
└── font/          # 前端管理界面：可视化操作控制台与数据展示
```

## 🚀 快速开始
### 环境依赖
- JDK 1.8+
- Maven 3.6+
- Node.js 14+

### 1. 启动中心服务端
进入 `server` 目录，执行 Maven 构建并启动服务：
```bash
cd server
mvn clean install
mvn spring-boot:run
```

### 2. 启动爬虫采集节点
进入 `crawlernode` 目录，构建并启动采集节点（支持部署多个实例）：
```bash
cd crawlernode
mvn clean install
mvn spring-boot:run
```

### 3. 启动前端管理界面
进入 `font` 目录，安装依赖并启动前端开发服务：
```bash
cd font
npm install
npm run dev
```
启动后访问对应本地地址即可进入可视化管理界面。
